# AI Image Gen - iOS AI 生图应用

支持多种 AI 生图协议的 iOS 应用，可自由添加和管理供应商。

## ✨ 功能

- 🏪 **供应商管理** — 自由添加、编辑、删除多个生图服务商
- 🔌 **多协议支持** — OpenAI 兼容协议、Stable Diffusion WebUI、ComfyUI
- 🔧 **自定义配置** — 每个供应商独立配置 API URL、API Key、模型
- 📐 **多种尺寸** — 支持 1024、1080p、2K、4K 等多种分辨率
- 📡 **连通性检测** — 一键测试供应商 API 是否可用
- 📜 **历史记录** — 保存所有生成记录，支持查看详情和删除
- 🌙 **深色主题** — 原生暗色风格，美观大方

## 📦 安装

从 GitHub Actions 下载 `.ipa` 后用以下方式安装：
- **AltStore** / **SideStore** — 免费自签（每7天重签）
- **爱思助手** — 连电脑安装

## ⚙️ 使用

1. 打开「设置」→ 点右上角 **+** 添加供应商
2. 选择协议类型（OpenAI 兼容 / SD WebUI / ComfyUI）
3. 填入 API 地址和 API Key
4. 点 **测试连通性** 确认可用
5. 回到「生成」页，输入提示词开始生图

## 🔄 更新

推送代码到 GitHub 后，Actions 自动构建新版 IPA。
