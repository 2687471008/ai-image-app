# AI Image Gen - iOS AI 生图应用

支持多种 AI 生图协议的 iOS 应用，可自定义 API 地址和密钥。

## ✨ 功能

- 🎨 **多协议支持**：OpenAI DALL-E 3、OpenAI 兼容协议、Stable Diffusion WebUI、ComfyUI
- 🔧 **自定义配置**：可自由配置 API URL、API Key、模型名称
- 📐 **多种尺寸**：支持 1:1、16:9、9:16 三种比例
- 📜 **历史记录**：保存所有生成记录，支持查看详情和删除
- 🌙 **深色主题**：原生暗色风格，美观大方

## 📦 安装

从 GitHub Actions 下载 `.ipa` 后用以下方式安装：
- **AltStore** / **SideStore** — 免费自签
- **爱思助手** — 连电脑安装

## ⚙️ 配置

1. 打开「设置」页面
2. 选择生图服务商
3. 填入 API 地址和 API Key
4. 可选：选择模型、尺寸、步数

## 🔄 更新

推送代码到 GitHub 后，Actions 自动构建新版 IPA。
